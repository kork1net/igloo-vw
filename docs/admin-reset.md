# איפוס שחקן

למנהלים מופיע כפתור **איפוס שחקן** בתיק החפצים, לצד כלי הניהול האחרים.
מזינים שם שחקן, לוחצים על V, קוראים את פירוט האיפוס ומקלידים שוב את שמו לאישור.
אפשר לאפס גם שחקן שאינו מחובר. הפעולה אינה ניתנת לביטול מתוך המשחק.

האיפוס מחזיר את השחקן למצב ההתחלתי: יתרת הכסף ההתחלתית שב־`server/economy.json`,
צבע הגוף שנבחר בהרשמה בלבד, אפס ניקוד דירוג ושיאים, וללא התקדמות במשימות,
פריטים שנרכשו או התקבלו ולבוש נוסף. התראות על מתנות קודמות מוסרות.
שם המשתמש, הסיסמה, המגדר והרשאות הניהול נשמרים. לכן מנהל שאופס ממשיך לקבל
את כל הפריטים ואת הדרגה המרבית מכוח הרשאותיו.

כל הכרטיסיות המחוברות של השחקן מתנתקות והוא יכול להתחבר שוב באותם פרטים.
החלפה ומשחקון פעילים מבוטלים. מספר הבקשה נשמר לצורך מניעת איפוס כפול
במקרה של ניסיון חוזר אחרי ניתוק; רישומי מתנות קודמות נשמרים ללא התראות כדי
שניסיון חוזר לשליחת מתנה ישנה לא ישחזר כסף שנמחק.

בדיקות: `node tests/admin-reset.cjs` ו־`node tests/menu-browser.cjs --inventory --world --trade`.
הבדיקות משתמשות בחשבונות ובקבצי שמירה זמניים ונפרדים.
