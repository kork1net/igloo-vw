# חסימת החנות

`shared/square.json` מגדיר את מיקום החנות, קנה המידה, קו העומק וגבולות
הקירות והדלת ביחס לתמונת המקור. הנתונים משותפים ללקוח ולשרת.

`shared/collision.js` בודק תנועה מול הקירות שמתחת לקו העומק. הפתח לדלת
נשאר פנוי, ואפשר לעבור מאחורי החנות מעל הקו. הבדיקה נעשית סביב רגלי
השחקן, כוללת החלקה לאורך קיר ומונעת דילוג דרך הקיר בתנועה מהירה.
היא פועלת גם כשהשרת משלים תנועה בכרטיסייה ברקע. נקודת הכניסה לחנות
ממוקמת בחוץ, מול הדלת.

נדרשת גרסת Node התומכת ב־require של ESM סינכרוני (Node 22.12 ומעלה).
בדיקות: `node tests/collision.cjs`, `node tests/background-movement.cjs`.
