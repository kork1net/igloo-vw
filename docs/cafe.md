# בית הקפה הזמני

המבנה והדלת בכיכר נטענים מ־`public/assets/enviroment/coffee-building.png`
ו־`coffee-building-door.png`. לשתי התמונות אותו קנבס, ומציגים אותן באותו מיקום וקנה מידה.
מיקום המבנה, קו העומק, גבולות הקירות ופתח הדלת מוגדרים ב־`shared/square.json`
תחת `cafe`. הקירות משותפים ללקוח ולשרת דרך `getSquareColliders`.

לחיצה על הדלת שולחת את השחקן לכניסה; כשהוא מגיע, נפתח האזור `Cafe`.
לחיצה כפולה גורמת לריצה, כמו בדלת החנות. ביציאה חוזרים לכיכר ליד דלת בית הקפה.
הדלת מקבלת קו מתאר לבן במעבר עכבר. פנים בית הקפה הזמני נמצא ב־`src/game/scenes/Cafe.js`.

השרת מפריד בין חדרי `Game`, `Shop` ו־`Cafe`, כולל שחקנים וצ׳אט.
תיק החפצים והלבוש ממשיכים לעבוד בפנים. קטלוג החנות והמיניגיים נשארים באזורים הקיימים שלהם.

בדיקות: `node tests/collision.cjs`, `node tests/accounts.cjs`,
`node tests/menu-browser.cjs --inventory --world --cafe`.
